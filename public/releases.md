# ConnectOnion release channels

## Stable — 1.6.0

Install the production recommendation with:

```bash
pip install connectonion
```

## Preview — 1.7.0a1

The 1.7 preview adds audience-scoped HTTP routes, expanded ACP support,
Telegram messaging, and tighter account-safety boundaries. Install it
explicitly while it is being exercised end to end:

```bash
pip install connectonion==1.7.0a1
```

Preview releases do not replace the stable version shown on the main site.

# 1.8.9b7 — Claude Station can start in the browser

An opt-in preview. Stable remains 1.8.8.

- Take control of a newly opened `co claude` terminal before its first prompt.
  The first browser message creates a native Claude session; later turns resume
  it, and control can return to the terminal.
- If Claude fails before initialization, the pending browser message gets a
  prompt rejection instead of a 60-second ACK timeout. The draft remains.
- Verified workspace edits still require the paired owner's **Allow once** or
  **Reject** decision. Shell, MCP, and other tool approvals remain unavailable
  in this preview.

The first-turn flow passed in local Chromium with Haiku, including a real Write
approval, the resulting file and reply, a narrow-phone layout check, and
return to the terminal. See [issue #1776](https://github.com/openonion/connectonion/issues/1776).

Install: `python -m pip install --upgrade 'connectonion==1.8.9b7'`.
